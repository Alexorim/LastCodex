# 🧠 Red Neuronal de Documentación — LastCodex / OrnaForecast

Esta carpeta contiene la bóveda de conocimiento (**Obsidian Vault**) de **LastCodex**.

## 🚀 Cómo abrir en Obsidian
1. Abre **Obsidian**.
2. Selecciona **"Abrir carpeta como bóveda" (Open folder as vault)**.
3. Elige la carpeta `obsidian/codex-vault`.
4. Abre la **Vista de Grafo** (`Ctrl + G`) para explorar la red neuronal interactiva de sinapsis.
5. Puedes comenzar la navegación desde `00 - Nodo Central (MOC) - LastCodex.md`.

## 📂 Estructura de Nodos
- **`00 - Nodo Central (MOC)`**: Nexo central de sinapsis.
- **`01 - General/`**: Visión, versiones (`v1.3.0`), arquitectura multicapa y stack tecnológico.
- **`02 - Modulos/`**: Forecast de gremios, códice de Orna, rastreador de eventos y configuración.
- **`03 - Servicios/`**: Lógica reactiva (CodexService, MaterialsService, TimerService, SettingsService, BackButtonService).
- **`04 - Paginas/`**: Vistas (Home, Calendar, Search, Codex, CodexClasses, Events, Settings).
- **`05 - Modelos/`**: Tipos TypeScript e interfaces de datos.
- **`06 - Plataformas/`**: Android (Capacitor), Desktop (Electron) y Web (PWA / Vercel).
- **`07 - Scripts/`**: Automatización de APKs, generación de iconos y web scraping.
- **`08 - Utilidades/`**: Canvas gráfico, internacionalización y sprites.
- **`09 - Actualizaciones/`**: Changelog maestro, historial exhaustivo de versiones (`v1.0.0`, `v1.1.0`, `v1.2.0`, `v1.3.0`) y plantilla para registrar futuras versiones.
